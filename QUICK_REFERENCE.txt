SAMPLE QUERIES
================================================================================

-- List upcoming flights
SELECT * FROM daily_flight_schedule 
WHERE flight_date >= CURDATE();

-- Find passenger bookings
SELECT p.first_name, p.last_name, f.flight_number, b.seat_number
FROM passengers p
JOIN bookings b ON p.passenger_id = b.passenger_id
JOIN flights f ON b.flight_id = f.flight_id
WHERE p.passenger_id = 1;

-- Airport statistics
SELECT * FROM airport_operations 
ORDER BY total_flights DESC;

-- Book a ticket (stored procedure)
CALL book_ticket(1, 2, '15A');

-- Cancel booking (stored procedure)
CALL cancel_booking(5);

-- Revenue by flight
SELECT f.flight_number, COUNT(b.booking_id) AS bookings, 
       SUM(t.price) AS revenue
FROM flights f
LEFT JOIN bookings b ON f.flight_id = b.flight_id
LEFT JOIN tickets t ON b.booking_id = t.booking_id
WHERE b.booking_status = 'Confirmed'
GROUP BY f.flight_id;

TROUBLESHOOTING
================================================================================

Problem: Apache won't start
Solution: Change port 80 to 8080 in httpd.conf

Problem: MySQL won't start
Solution: Check if another MySQL service is running

Problem: Connection failed
Solution: Verify credentials in config.php

Problem: Stored procedure error
Solution: Execute procedures one at a time with correct DELIMITER

Problem: PHP files download instead of execute
Solution: Ensure Apache is running and files are in htdocs

Problem: Trigger not firing
Solution: Check trigger syntax and table names

NORMALIZATION QUICK CHECK
================================================================================
1NF: ✓ All attributes atomic (no multi-valued attributes)
2NF: ✓ No partial dependencies (all depend on full PK)
3NF: ✓ No transitive dependencies (no non-key → non-key)

ACID PROPERTIES
================================================================================
A - Atomicity:    All or nothing (booking transaction)
C - Consistency:  Constraints maintained (seats >= 0)
I - Isolation:    Concurrent transactions isolated
D - Durability:   Committed data persists

JOIN TYPES
================================================================================
INNER JOIN: Only matching records
LEFT JOIN:  All from left + matching from right
RIGHT JOIN: All from right + matching from left
CROSS JOIN: Cartesian product

AGGREGATE FUNCTIONS
================================================================================
COUNT()  - Count rows
SUM()    - Total of values
AVG()    - Average value
MAX()    - Maximum value
MIN()    - Minimum value

GROUP BY: Groups rows for aggregation
HAVING:   Filters groups (use after GROUP BY)
